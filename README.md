# Chat App

A real-time chat application with a live article polling feed, built with React + TypeScript + Vite.

## Prerequisites

- Node.js 18+
- npm 9+

## Setup

```bash
git clone git@github.com:Offthearc/chat-app.git
cd chat-app
npm install
```

## Run dev server

```bash
npm run dev
```

Open http://localhost:5173 in your browser.

## Run tests

```bash
npm test
```

## Lint

```bash
npm run lint
```

## Build

```bash
npm run build
```
